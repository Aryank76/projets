Download and install

Follow these steps once. You only need to do this one time.

ReplyPilot for Chrome

Get the extension as a zip file and install it in developer mode.

Download .zip
Version 1.0Chrome, Edge, Brave
  1. Unzip the fileRight-click replypilot.zip and choose Extract All. Keep the extracted folder somewhere permanent, such as Documents.
  2. Open the extensions pageIn your browser, go to chrome://extensions. On Edge use edge://extensions.
  3. Turn on Developer modeUse the toggle in the top-right corner of the page.
  4. Load the extensionClick Load unpacked, open the extracted mail-ai-reply-ready folder, and select the extension folder inside it.
  5. Try it in GmailOpen mail.google.com, open an email, and click Reply. You will see the AI Reply button.
Don't delete the extracted folder. The browser loads the extension from it. Select the inner extension folder, not the outer one. If the button doesn't show up, refresh Gmail.

Questions

Is ReplyPilot free?

Yes. You can download and use it at no cost.

Does it send emails for me?

No. It only writes a draft in the reply box. You review it and press Send yourself.

What happens to my email content?

When you click AI Reply, the text of that email is sent to generate the draft. It is not used to build a profile of you, and your inbox is not stored.

Why do I need Developer mode?

The extension is installed from a file rather than the Chrome Web Store. Developer mode lets your browser load it.

Which email services are supported?

Gmail in the browser for now.
